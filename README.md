# Sainath Bejgamwar — Portfolio

A responsive, dark navy developer portfolio built with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser. For a smoother local development experience, use the VS Code Live Server extension.

## Before publishing
1. Add the resume PDF at `assets/resume.pdf`.
2. Replace placeholder LinkedIn and GitHub links in `index.html`.
3. Replace project repository placeholders with real repository URLs.
4. Verify all content and contact details are intended to be public.

## Publish with GitHub Pages
1. Create a public repository (for example, `sainath-portfolio`).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After deployment completes, use the URL shown in the Pages settings.

GitHub Pages serves static files; it does not run a WordPress/PHP installation.
